Dove salvo i tuoi dati?

Ore e assenze finiscono in un file attivita.json tuo. Nessun server: la pagina lo legge e lo salva solo lì.

Hai già un attivita.json?

Collega il repo GitHub

  1. Crea su GitHub un repo privato, anche vuoto.
  2. Crea un token fine-grained con accesso solo a quel repo e permesso Contents: Read and write.
  3. Incolla qui repo e token: il token resta in questo browser.

Archivio dei dati

Collega un altro dispositivo: inquadra il codice con la fotocamera del telefono, o di un altro PC, e apri il link. Contiene l'accesso al tuo repo privato: mostralo solo ai tuoi dispositivi, non mandarlo in chat o per mail.

Collega Azure DevOps

  1. Su Azure DevOps apri User settings → Personal access tokens e crea un token per All accessible organizations con i permessi Work Items: Read & write, Project and Team: Read e User Profile: Read.
  2. Incolla il token: compaiono le tue organizzazioni e poi i progetti. Spunta quelli da cui leggere le ore.
